# Осознанные отличия от оригинала

Список расхождений копии с `skylum.com/luminar` и причины каждого. Всё, чего здесь нет,
воспроизводилось по эталону из `research/`.

## Намеренно не переносилось

| Что | Причина |
| --- | --- |
| Google Tag Manager, Facebook Pixel, TikTok, Criteo, Reddit, Bing, Rakuten, Impact, AppsFlyer, Microsoft Clarity | Трекеры и рекламные пиксели. Копия не должна отправлять данные посетителя третьим лицам. |
| Виджет чата Zendesk | Сторонний сервис, требует собственного аккаунта и ключа. |
| Баннер согласия на cookie (Cookie Information) | Следствие отсутствия трекеров: собирать согласие не на что. |
| Виджет отзывов Trustpilot | Внешний сервис с платной интеграцией. |
| jQuery, jQuery Migrate, Swiper, Slick, SweetAlert2 | Интерактив переписан на React (~150 KB JS сэкономлено). Поведение сохранено. |

## Технические отличия реализации

| Что | Как в оригинале | Как в копии | Причина |
| --- | --- | --- | --- |
| Обратный отсчёт | Дедлайн приходит с сервера | Дедлайн вычисляется от момента сборки (`PROMO_WINDOW_DAYS = 10` в `src/lib/constants.ts`) | Бэкенд акции не воспроизводится; таймер остаётся «живым» в любой момент демонстрации. |
| Карусель Pro Tools | Slick с бесконечной прокруткой и клонированными слайдами | CSS scroll-snap + стрелки, свайп и клавиши | Нативный скролл даёт корректный свайп на тач-устройствах без библиотеки. Слайды не клонируются: листание останавливается на краях. |
| Форма подписки | Отправка на бэкенд Skylum | Клиентская валидация + сообщение об успехе | Отправлять реальные адреса на чужой бэкенд недопустимо. |
| Переключатель языка | Переключает локаль сайта | Меняет подпись, страница остаётся на английском | Локализации других языков в задании нет. |
| Иконки блока «AI RECOMMENDS LUMINAR» | Фирменные SVG сервисов | Монохромные SVG-эквиваленты собственной отрисовки | Оригинальные логотипы — товарные знаки третьих лиц. |
| Ссылки навигации и футера | Внутренние страницы Skylum | Ведут на реальные адреса `skylum.com` | Копируется одна страница `/luminar`, остальные разделы вне задания. |
| Мега-меню «More» и «Features» | Полный набор разделов из CMS | Состав, видимый в разметке оригинала на момент снятия эталона | Часть пунктов подгружается динамически из CMS. |

## Оптимизация ассетов

Все медиа перекодированы, чтобы уложиться в целевые показатели Lighthouse:

| Ассет | Было | Стало |
| --- | --- | --- |
| Видео (44 файла) | 180 MB, H.264 до 4K | 37 MB — H.264, ширина ≤ 1280, CRF 30, без звука |
| Растровые изображения | 32.6 MB (JPG/PNG) | 10.9 MB — WebP q78, ширина ≤ 1600 |

Оригиналы сохранены в `research/video-original/` и `research/img-original/` и не попадают в сборку.
Визуально на контрольных ширинах разница не читается; при сильном увеличении возможна
чуть меньшая детализация фотографий.

## Точность геометрии

Замеры сняты на 1440 px (`research/data/metrics-all.json`). Расхождение по высоте секций:

| Секция | Оригинал | Копия | Δ |
| --- | --- | --- | --- |
| hero | 1366 | 1368 | +2 |
| Discover possibilities | 995 | 988 | −7 |
| Choose once, edit forever | 986 | ~985 | ~0 |
| 5 reasons | 1411 | ~1390 | −21 |
| Discover all capabilities | 617 | 592 | −25 |
| Pro Tools | 1144 | 1115 | −29 |
| Just 4 steps | 702 | 715 | +13 |
| Retouch portrait | 702 | 715 | +13 |
| Edit a whole photoshoot | 764 | ~750 | −14 |
| Нижний баннер | 980 | 1006 | +26 |
| FAQ | 1041 | 1061 | +20 |
| App Requirements | 111 | 97 | −14 |
| Футер | 630 | 627 | −3 |

Итог по документу — около 2 % (11 448 px против 11 204 px). Расхождения внутри секций
возникают из-за незначительных различий в переносах строк и высотах карточек с текстом
переменной длины.

## Шрифт

Roobert — коммерческий шрифт Displaay Type Foundry, лицензированный Skylum. Файлы `woff2`
взяты с CDN оригинала и хранятся в `public/assets/fonts/` только для демонстрации тестового
задания. Для любого другого применения потребуется собственная лицензия либо замена на
геометрический гротеск с близкими метриками.
