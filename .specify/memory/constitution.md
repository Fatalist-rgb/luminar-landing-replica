# Luminar Landing Replica Constitution

**Проект**: пиксель-точная копия одностраничного лендинга `https://skylum.com/luminar`
**Назначение**: тестовое задание — оценивается качество итогового результата, адаптивность и корректная работа элементов страницы.

## Core Principles

### I. Fidelity First (NON-NEGOTIABLE)

Эталон — живой оригинал `https://skylum.com/luminar`, а не приблизительное впечатление от него.

- Каждая секция реализуется по измеренным значениям оригинала: размеры шрифтов, line-height,
  отступы, радиусы, цвета, градиенты, порядок и вложенность блоков.
- Любое отклонение от оригинала должно быть осознанным и зафиксированным в `research/DEVIATIONS.md`
  с причиной (недоступность ассета, лицензия, платный сторонний виджет).
- Контент (заголовки, подзаголовки, списки, тексты FAQ, пункты меню и футера) переносится дословно,
  включая типографику символов (`’`, `–`, `®`, эмодзи).
- Визуальная проверка — обязательный шаг приёмки: посекционные скриншоты копии сравниваются
  со снимками оригинала в `research/screens/`.

### II. Responsive by Construction

Адаптивность закладывается при вёрстке каждого блока, а не «чинится» в конце.

- Обязательные контрольные ширины: **390** (mobile), **768** (tablet), **1024** (laptop),
  **1440** (desktop, эталон замеров), **1920** (wide).
- Ни на одной ширине от 320px не допускается горизонтальный скролл body и обрезка контента.
- Мобильные раскладки повторяют мобильную версию оригинала (бургер-меню, одноколоночные сетки,
  переносы заголовков), а не являются механическим сжатием десктопа.
- Изображения — `srcset`/`sizes` или `next/image`; тяжёлые видео не грузятся на мобильных,
  если оригинал их там скрывает.

### III. Interaction Parity

Интерактивные элементы работают, а не имитируются статикой. Обязательный минимум:

- Прилипающая шапка с мега-меню (desktop) и полноэкранным бургер-меню (mobile).
- Промо-бар с живым обратным отсчётом, появляющийся по скроллу.
- Интерактивный список фич с переключением медиа-превью.
- Before/After слайдеры с перетаскиванием (mouse + touch) и пошаговым режимом.
- Карусель Pro Tools со стрелками, свайпом и переключателем Original / Apply.
- FAQ-аккордеон и раскрывающийся блок системных требований.
- Галерея пресетов с одновременным применением эффекта ко всем фото.

Каждый интерактив должен быть управляем с клавиатуры и не ломаться при быстром повторном клике.

### IV. Accessible & Performant

- Семантическая разметка: один `h1`, корректная иерархия заголовков, `nav`/`section`/`footer`,
  `alt` у всех значимых изображений, `aria-expanded`/`aria-controls` у аккордеонов и меню.
- Видимый focus-ring, доступность всех интерактивов с клавиатуры, соблюдение `prefers-reduced-motion`.
- Целевые показатели Lighthouse (mobile, production build): **Performance ≥ 85**,
  **Accessibility ≥ 95**, **Best Practices ≥ 95**, **SEO ≥ 95**.
- CLS ≤ 0.05: у всех медиа заданы размеры или aspect-ratio.

### V. Clean Component Architecture

- Одна секция страницы — один компонент в `src/components/sections/`; переиспользуемые примитивы
  (кнопка, таймер, аккордеон, слайдер) — в `src/components/ui/`.
- Весь контент выносится в типизированные модули данных `src/data/*.ts`; JSX не содержит
  «зашитых» строк контента и списков.
- Server Components по умолчанию; `"use client"` — только там, где нужен стейт, эффекты или
  обработчики событий.
- Никаких jQuery/Swiper/Slick из оригинала: интерактив пишется на React с нативным CSS scroll-snap
  либо минимальной собственной логикой.

### VI. Self-Contained Assets

- Все изображения, видео, иконки и шрифты скачиваются в `public/assets/` — прод-сборка не обращается
  к `media.macphun.com` и другим сторонним CDN.
- Трекеры, пиксели и сторонние аналитические скрипты оригинала (GTM, Facebook, TikTok, Criteo,
  Clarity, Zendesk, Cookie Information) в копию **не** переносятся.
- Ассеты являются собственностью Skylum и используются исключительно для демонстрации тестового
  задания; это фиксируется в `README.md`.

## Technology Constraints

- **Framework**: Next.js 15 (App Router) + React 19 + TypeScript (strict).
- **Стилизация**: Tailwind CSS 4 с токенами дизайна (цвета, шрифты, брейкпоинты) в `globals.css`.
- **Анимации**: CSS-переходы и `IntersectionObserver`; тяжёлые анимационные библиотеки не подключаются
  без явной необходимости.
- **Зависимости**: минимальный набор. Каждая новая runtime-зависимость требует обоснования —
  «есть в оригинале» обоснованием не является.
- **Деплой**: Vercel, production-сборка, публичная ссылка.
- **Node**: 20+; менеджер пакетов — npm.

## Quality Gates

Работа считается завершённой только когда пройдены **все** пункты:

1. `npm run build` завершается без ошибок и без TypeScript-ошибок.
2. `npx tsc --noEmit` и `npm run lint` — чисто.
3. Посекционные скриншоты копии сняты на 390 и 1440 и сопоставлены с `research/screens/`;
   расхождения либо устранены, либо занесены в `DEVIATIONS.md`.
4. Ручной прогон интерактивов из принципа III на desktop и mobile.
5. Прогон на 320/390/768/1024/1440/1920 без горизонтального скролла.
6. Lighthouse-прогон с показателями из принципа IV.
7. Прод-деплой доступен по публичной ссылке, консоль без ошибок.

Заявление «готово» без выполненной проверки запрещено: сначала прогон, затем вывод.

## Governance

- Конституция имеет приоритет над привычками и «как быстрее»; при конфликте требований
  побеждает принцип с меньшим номером.
- Изменение принципа фиксируется bump-ом версии и записью в таблице ниже.
- Спецификация (`specs/001-luminar-landing-replica/spec.md`) и план не могут противоречить конституции;
  при расхождении правится спецификация.
